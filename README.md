# Global CO2 Emissions Analysis Project

## Overview

This project analyzes global CO2 emissions data from 1750 to 2022, focusing on emissions from various sources including coal, oil, gas, cement production, and flaring. The analysis provides insights into country-level contributions to global emissions and their environmental impact.

## Features

### Data Analysis
- Country-wise emissions tracking
- Source-specific emission analysis (coal, oil, gas, cement, flaring)
- Per capita emission calculations
- Historical trend analysis from 1750-2022

### Tools Used
- Python for data manipulation
- Pandas for data analysis
- Matplotlib and Seaborn for visualization
- Plotly for interactive visualizations

## Dataset

The dataset includes comprehensive information about:
- Country-level CO2 emissions
- ISO country codes
- Yearly emissions data from 1750-2022
- Emission sources breakdown
- Per capita calculations
